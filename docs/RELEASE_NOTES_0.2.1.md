# MemoryBridge 0.2.1 MVP test 1 release notes

Release tag: `v0.2.1-mvp-test.1`
Audience: internal user testing
Production status: not production-ready

## User-visible additions

- Five-step first-run workflow with vault location/capacity, offline/API/demo mode, first import,
  and review summary.
- Vault Storage screen with device/free/vault/category sizes, counts, refresh, progress,
  cancellation, and write verification.
- Bundled synthetic ChatGPT demo created at runtime; no real export is shipped.
- Import progress, cancellation, detailed import records, branch/malformed counts, and post-import
  integrity verification.
- Honest missing-drive and locked-instance states with no fallback writes; registered drives reopen
  by vault identity.
- Independent provider capability tests and visible persisted results.
- Reviewable provider-memory scope assignment.
- Distinct resume, force-chat, project, and full derived-intelligence rebuild controls.
- Content-free **Copy diagnostic report**.

## Integrity repairs

- ChatGPT current-node/parent tree reconstruction prevents mutually exclusive branches from being
  flattened together.
- ZIP parsing is streaming and bounded for archive, entry, cumulative expansion, entry count,
  compression ratio, traversal, cancellation, and progress.
- Legacy memory provenance migrates to first-class multi-chat evidence with backup, explicit scope,
  preserved confirmation/history, review fallback, idempotency, and interrupted-run recovery.
- MCP defaults to current truth, requires explicit opt-ins for review/disputed/history, and enforces
  scope even for direct IDs.
- Heartbeats serialize writes, fence ownership, contain drive errors, and cannot recreate/release a
  foreign lock during shutdown.
- Full derived rebuilds bulk-populate FTS transactionally; normal startup remains incremental.

## Verification snapshot

- Formatting, ESLint, TypeScript, production build, and npm audit pass.
- 69 unit/integration tests and one full Electron workflow are in the local gate.
- The synthetic 1,000-conversation/50,000-message benchmark passes in 22.81 seconds on the recorded
  test machine.
- The built/unpacked packaged application passes the same onboarding/import/search/evidence/restart
  workflow.
- Windows x64 NSIS installer and uninstall support are generated by electron-builder.
